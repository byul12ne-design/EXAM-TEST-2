# Archive 문서 안내

이 폴더는 현재 운영 문서에서 중복되거나 완료된 계획성 문서를 보관한다.

Archive 문서는 기본 운영 진입점이 아니다. 최신 상태 확인은 아래 문서를 우선한다.

| 목적 | 최신 문서 |
|---|---|
| 인증/배포 운영 절차 | `docs/operations/AUTH_AND_DEPLOY_OPERATION_GUIDE.md` |
| Vercel env 운영 상태 | `docs/operations/VERCEL_ENV_STATUS.md` |
| Firestore Rules 정책과 운영 상태 | `docs/security-remediation/FIREBASE_RULES_PLAN.md` |
| smoke test 결과 | `docs/operations/SMOKE_TEST_RESULTS.md` |

Archive 문서를 다시 활성 문서로 옮기기 전에는 현재 코드, Firebase Rules, Vercel env, smoke test 결과와 일치하는지 먼저 재검토한다.
